objective: Close PERF-07 (quick-XML zero-copy in the DMN XML loader) by removing the per-element `BytesStart::into_owned()` copy from every streaming dispatch loop, borrowing attribute/name data directly from the reusable read buffer and carrying only owned `Attrs`/`parent`/`end_local` into the recursive parse.
tasks:
  - id: T1
    name: Eliminate per-element `into_owned()` across all dispatch loops
    description: |
      The default quick-xml idiom `let e = e.into_owned();` was applied on
      every `Event::Start(e)` in every dispatch loop in
      `engine/src/dmn/parser.rs`. `BytesStart::into_owned()` re-copies the
      element name and every attribute byte into a fresh heap allocation per
      start event — thousands per document — defeating zero-copy and
      duplicating the work `collect_attrs` then does again. Removed from all
      loops below the root. Each loop now reads a borrowed `Event::Start(e)`,
      extracts only what it needs (local name as an owned `String`, and an
      owned `Attrs` map only in arms that recurse into a sub-parse needing
      attrs), and drops the borrow. `read_event_into` ties the event's
      lifetime to `&mut self.reader`; non-lexical lifetimes end `e`'s borrow at
      its last use (`collect_attrs(&e)` or `local_name_str(e.name())`), so the
      subsequent recursive `&mut self` parse is sound with no owned copy.
    files_modified:
      - engine/src/dmn/parser.rs
  - id: T2
    name: Thread owned `Attrs`/`parent`/`end_local` through sub-parsers
    description: |
      To make the borrow release possible, every sub-parser signature changed
      from `&mut self, start: &BytesStart, …` to take pre-collected owned data:
      `attrs: Attrs` (a `HashMap<String,String>` alias) where the body read
      attributes, `parent: &str` where it only needed the element local name
      for close-tag matching, or just `end_local: &str` where the start was
      unused. This severs the buffer borrow before the `&mut self` recurse.
      20 methods take `Attrs`; 5 take `parent`; 2 take only `end_local`;
      `parse_dmndi_block` takes nothing. The public API
      (`parse_dmn`/`parse_dmn_bytes`/`parse_dmn_file`/`parse_dmn_with_cache`) is
      unchanged — all parse methods are private.
    files_modified:
      - engine/src/dmn/parser.rs
  - id: T3
    name: Root `<definitions>` exception (one `into_owned()` per document)
    description: |
      The single remaining `into_owned()` is on the root `<definitions>`
      element, one allocation per *document* (negligible). It is required
      because resolving the root namespace calls `self.resolve_element_ns`
      (`&self.reader`), but `read_event_into` ties the borrowed event's
      lifetime to `&mut self.reader` — you cannot touch the reader (even
      `&self`) while the borrowed event is held. `into_owned()` severs that
      borrow for this one element. Every element below the root is zero-copy.
      Documented honestly in the module doc and inline.
    files_modified:
      - engine/src/dmn/parser.rs
  - id: T4
    name: Regression guard + behavior verification
    description: |
      Added `parser_zero_copy_preserves_attrs_cdata_and_entities`: parses a
      decision table exercising every refactored path (definitions attrs →
      decision attrs → decisionTable hitPolicy attr → input/output clause
      attrs → rule attrs → ruleEntry CDATA cell + `&lt;` GeneralRef → FEEL
      text child) and asserts the IR matches. Plus the full DMN integration
      suite confirms behavior preservation: `dmn_round_trip` (14),
      `dmn_parser` (8 incl. XXE rejection, CDATA, 1.1/1.3/1.5 namespaces,
      element order, itemDefinition clause 7), `hit_policy_core` (5),
      `hit_policy_advanced` (9), `tck_sweep` (51 vectors), `feel_cache_wiring`
      (6) — all green through the new zero-copy path.
    files_modified:
      - engine/src/dmn/parser.rs
