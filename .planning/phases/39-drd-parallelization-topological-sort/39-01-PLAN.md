    name: Non-recursive level-by-level evaluate with rayon parallelism
    description: |
      Rewrite `DecisionEvaluator::evaluate` so upstream decisions are resolved level-by-level instead
      of via recursive `self.evaluate`. One outer read guard on `self.shared` is held for the whole
      call; `&SharedDmnModel` (Sync) is shared into rayon tasks. The DRD order is precomputed before
      the parallel section, so no `drd_order_cache` writes occur concurrently.
      Within a level, each decision's input scope is built from `request.inputs` + the merged context
      of all earlier levels (already complete — the barrier between levels guarantees correctness).
      Levels with >1 decision use `rayon::slice::ParallelIterator` + `collect` (no shared mutable
      state; results gathered into a Vec then merged). Single-decision levels stay sequential to
      avoid rayon overhead on the common dependency-chain case.
      Add private `evaluate_single_decision(shared, decision, scope) -> Result<SingleDecisionOutput>`
      that performs the table/no-table evaluation + metrics increment (no recursion, no shared lock).
      Public `evaluate` signature and `EvaluateResult` shape are unchanged; trace events are emitted
      in level→id order after collection. `reload` unchanged.
