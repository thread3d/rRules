<objective>
Implement the FEEL AST cache (`FeelAstCache = DashMap<String, Arc<FeelExpression>>`), wire it into the Phase 29 DMN IR loader so every cell is pre-parsed at load time, and scaffold the OMG TCK FEEL test harness (loader + runner + small vendored subset, full passage deferred to Phase 35).

Purpose: DMN-18 — the AST cache prevents the #1 DMN performance bug (4-6x re-parse throughput loss). A 30-cell table evaluated 10k times does ~30 parses (at load), not 300k. The evaluator-takes-`&FeelExpression`-never-re-parses contract is the type-level guarantee. The TCK harness scaffolds conformance testing now so Phase 35 only needs to expand the vector set.

Output: Filled `cache.rs` with `FeelAstCache`; `engine/src/dmn/parser.rs` extended to pre-parse all FEEL cells into the cache at load time; `engine/tests/feel_cache_wiring.rs` integration test; `engine/tests/feel_tck_subset.rs` TCK harness scaffold.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .dmn file cells -> IR loader -> cache | Untrusted cell text is pre-parsed at load time; the parser's error recovery (31-01) handles malformed cells |
| Cached AST -> evaluator | The evaluator consumes borrowed Arc<FeelExpression>; the cache is read-only after load |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-31-09-01 | Denial of Service | AST cache unbounded growth from many distinct cells | low | accept | The cache is bounded by the IR's cell count (finite per .dmn file); a pathological .dmn is bounded by Phase 29's parser limits |
| T-31-09-02 | Tampering | Cache key collision (two different cells share a key -> wrong AST) | high | mitigate | Canonical key = (entry-point kind, trimmed content) hash (Pitfall 8); entry-point disambiguation tested; same-content-different-CDATA hits same entry (correct) |
| T-31-09-03 | Information Spoofing | Evaluator called with &str (re-parse bug) | high | mitigate | Type-level contract: no evaluate(&str) overload; compile-time + grep assertion; perf test confirms ~30 parses not 300k |
</threat_model>
