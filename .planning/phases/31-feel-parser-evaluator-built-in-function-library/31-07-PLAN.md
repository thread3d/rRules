<objective>
Implement the built-in function library registry (`HashMap<&str, BuiltinFn>`) and the first ~45 functions across the conversion, numeric, string, and list families, wiring the registry into the FunctionInvocation dispatch.

Purpose: DMN-17 part 1 — the built-in library is FEEL's standard function set. This plan lands the registry infrastructure (shared with 31-08) and the four largest families. Null propagation is the default (null arg -> Null) with documented spec exceptions (count([null])=1, all([])=true, any([])=false, sum([])->null). Numeric edge cases (div-by-zero, overflow, sqrt of negative) -> Null per CONTEXT.md.

Output: Filled `builtins.rs` with `BuiltinFn` type, `builtin_registry()` function returning the HashMap, and ~45 function implementations; `eval.rs` FunctionInvocation arm wired to call the registry.
</objective>
