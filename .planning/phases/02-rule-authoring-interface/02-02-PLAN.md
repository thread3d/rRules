## Phase 02-02: Decision Table Editor with ag-Grid

### Objective
Implement the decision table editor using ag-Grid for enterprise-grade spreadsheet features, supporting mixed editing (dropdowns for simple conditions, formulas for advanced users) and full row CRUD operations with drag-and-drop reordering.

**Purpose:** Business users need an intuitive way to create rules without coding. Decision tables provide a familiar spreadsheet interface that scales to complex rule sets while maintaining the flexibility of formula-based definitions.

**Output:**
- `ag-grid-table.tsx`: Enterprise ag-Grid component with custom cell renderers
- `cell-editors.tsx`: Dropdown and formula editors for mixed editing modes
- `row-operations.ts`: Row management with drag-and-drop reordering
- `decision-table-view.tsx`: Complete table UI with toolbar controls

### Context

**Locked Decisions from 02-CONTEXT.md:**
- **DT-U1**: Use ag-Grid spreadsheet library for enterprise-grade features and performance
- **DT-U2**: Mixed editing approach - simple cases use dropdown selectors, advanced users can edit formulas directly
- **DT-U3**: Full CRUD on rows - insert/delete/move with drag-and-drop reordering

### Implementation Details

**ag-Grid Configuration:**
- Enable `animateRows` for smooth transitions
- Set `rowSelection: "multiple"` and disable click-to-select
- Configure `defaultColDef` with editable, filterable columns
- Use `themeAlpine` or custom theme matching application design

**Column Types:**
1. **Text Column**: Simple string input with auto-sizing
2. **Dropdown Column**: Uses cellEditor: "agSelectCellEditor" for predefined options
3. **Formula Column**: Multi-line textarea or inline CodeMirror for expression editing

**Row Operations:**
- Insert row at selected position or end of table
- Delete selected rows (with confirmation)
- Duplicate row to create copy with new ID
- Drag-and-drop reordering using HTML5 API or dnd-kit library
