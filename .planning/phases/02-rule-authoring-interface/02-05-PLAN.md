## Phase 02-05: Inline Validation Engine

### Objective
Implement the inline validation engine with real-time syntax checking and save-time semantic validation, providing comprehensive error reporting UI with jump-to-error navigation.

**Purpose:** Immediate feedback is critical for a good authoring experience. Real-time syntax validation catches errors as users type, while semantic validation ensures rules are logically correct against the entity schema before they can be saved.

**Output:**
- `inline-validator.ts`: Comprehensive validation system with syntax and semantic checks
- `error-reporting.tsx`: Visual feedback UI with navigation capabilities
- `integration.ts`: Cross-component validation integration

### Context

**Requirements from ROADMAP.md:**
- **RULE-05**: Expression language support (MVEL-like syntax)
- **RULE-06**: Inline rule validation and error reporting

### Implementation Details

**Syntax Validation (Real-time):**
- Unmatched braces in `{placeholder}` syntax
- Invalid operator usage (standalone > or <)
- Missing clause terminators (IF without THEN)
- Unknown keywords or function names

**Semantic Validation (On-save):**
- Reference validation: all fields exist in entity schema
- Type checking: field type matches assigned value type
- Logic validation: detect contradictory conditions (x > 5 AND x < 3)
- Action validation: verify action exists and parameters match
