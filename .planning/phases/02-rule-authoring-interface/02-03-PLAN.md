## Phase 02-03: Guided Rule Editor with Hybrid Accordion

### Objective
Create the guided rule editor with a hybrid accordion structure that starts with all steps visible, collapses completed ones after review, and provides adaptive vocabulary display to toggle between technical and business-friendly terms.

**Purpose:** Business users need step-by-step guidance to create rules. A form-based approach with expandable sections reduces cognitive load while the vocabulary toggle ensures non-technical users can understand and contribute to rule creation.

**Output:**
- `hybrid-accordion.tsx`: Expandable section component with collapse-after-review behavior
- `vocabulary-toggle.tsx`: Technical-to-business vocabulary switching system
- `guided-form.tsx`: Form interface with smart defaults and step-by-step workflow

### Context

**Locked Decisions from 02-CONTEXT.md:**
- **GE-F1**: Hybrid accordion structure - start with all steps visible in expandable sections, collapse completed ones after review
- **GE-F2**: Adaptive display for business vocabulary - technical names by default with toggle to business terms
- **GE-F3**: Smart defaults with override - auto-generate rule name/description but allow easy editing

### Implementation Details

**Hybrid Accordion Structure:**
- Initial state: All sections expanded
- Review state: Sections collapse after user clicks "I've reviewed" or all required fields are filled
- Visual states: `expanded`, `collapsed`, `reviewed` (compact card with checkmark)

**Vocabulary Toggle System:**
- Technical mode: "field", "value", "operator"
- Business mode: "Customer Property", "Threshold Value", "Comparison Type"
- Persistent preference via localStorage

**Smart Defaults Engine:**
- Rule name auto-generated from first condition field
- Description suggested based on selected action
- Pre-populate common operators for numeric fields
