       - Setup: Build a DmnModel with three decisions where C requires B, B requires A (linear chain).

       - Assertion: Returns vec!["A", "B", "C"] — topological order with upstream first.

       **Test 2: `topological_order_diamond`** — Tests diamond pattern (D depends on B and C, both depend on A).
       - Setup: Four decisions where D requires [B, C], B requires [A], C requires [A].
       - Action: Call `resolve_drd_order("D")`.
       - Assertion: Returns order where A comes before both B and C, and both come before D. Exact order of B vs C may vary (both valid).

       **Test 3: `cycle_detection_a_to_b_to_a`** — Tests cycle detection for A→B→A.
       - Setup: Two decisions where A requires [B] and B requires [A].
       - Action: Call `resolve_drd_order("A")`.
       - Assertion: Returns `Err(DecisionEvalError::DrdCycle(...))` with both IDs in the cycle list.

       **Test 4: `skip_missing_references`** — Tests that references to non-existent decisions are skipped.
       - Setup: Decision D requires ["nonexistent_id"].
       - Action: Call `resolve_drd_order("D")`.
