  <files>engine/src/dmn/feel/builtins.rs</files>

  <action>
    In `engine/src/dmn/feel/builtins.rs`, implement the 3-argument form of `number()`.

    Step 1: Add a private helper function `built_in_number_3arg(args: &[Value]) -> Value` near `built_in_number` (around line 182, after the existing function). The function implements the DMN 1.5 Section 10.3.4.1 algorithm:

    1. Validate arity: if `args.len() < 3`, return `Value::Null`.
    2. Extract `from` (args[0]): must be `Value::String(s)`. If `Value::Null`, return `Value::Null`. Any other type, return `Value::Null`.
    3. Extract `grouping` (args[1]): if `Value::Null`, set to `None`. If `Value::String(s)` with `s.len() == 1`, validate the character is one of `{',', '.', ' '}`. If valid, use it. Otherwise return `Value::Null`.
    4. Extract `decimal` (args[2]): if `Value::Null`, set to `None`. If `Value::String(s)` with `s.len() == 1`, validate the character is one of `{',', '.'}`. If valid, use it. Otherwise return `Value::Null`.
    5. If both `grouping` and `decimal` are non-null and equal, return `Value::Null`.
    6. If `grouping` is non-null, remove all occurrences of the grouping character from `from` using `str::replace`.
    7. If `decimal` is non-null and not `'.'`, replace all occurrences of the decimal character with `'.'` in the cleaned string.
    8. Parse the normalized string with `Decimal::from_str()` (or `s.trim().parse::<Decimal>()`). On success, return `Value::Number(d)`. On failure, return `Value::Null`.

    Step 2: Update `built_in_number` at line 167 to dispatch to the 3-arg form when 3 or more arguments are provided. The dispatch logic:

    - If `args.len() >= 3`, call `built_in_number_3arg(args)` and return its result.
    - Otherwise, use the existing 1-arg logic (unchanged).

    The 1-arg form must remain unchanged: `Value::Null` → `Value::Null`, `Value::Number` → identity, `Value::String` → parse as Decimal, anything else → `Value::Null`.

    Do NOT modify the `null_unary`/`null_binary`/`null_ternary` helpers. Do NOT add f64 anywhere. Do NOT use regex for string manipulation — use `str::replace`.
  </action>
