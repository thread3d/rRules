# Phase 05 Plan 02: Scenario-Based Simulation Engine

## Objective

Build a what-if analysis engine for testing rule sets against alternate fact scenarios.

**Purpose:** Enable users to explore how rule outcomes change under different conditions without affecting production data. This is essential for validating rules before deployment and understanding edge cases.

**Output:** Complete simulation framework with scenario definitions, execution, and comparison results.

  <files>src/testing/simulation/scenario.rs</files>
  <action>Implement the scenario execution engine in `src/testing/simulation/scenario.rs`:

1. Run baseline scenario:
   - Load facts into working memory
   - Execute against rule set using runner from Plan 01
   - Capture all rule firing events and final state

2. Run alternate scenarios:
   - Override specific facts with alternate values
   - Re-run engine without reloading rules (efficiency)
   - Capture execution trace for comparison

3. Side-by-side comparison:
   - Compare rule firing lists between scenarios
   - Identify which rules changed behavior
   - Highlight fact differences that caused changes

4. Result generation:
   - `ComparisonResult` with diff output
   - Summary statistics (rules unchanged, changed, new)
   - Visual-friendly output for CLI and future UI

Integration: Use the BDD runner from Plan 01 for consistent execution.</action>
