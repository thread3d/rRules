**Decision Table Hit Policy Behavior:**

| Hit Policy | Behavior |
|------------|----------|
| First | Return first matching rule's outputs |
| Any | All rules with same inputs must have identical outputs (conflict detection) |
| Collect | Aggregate multiple matching rules using Sum, Min, Max, or Count |
| Override | Last matching rule wins |
| Priority | Use ruleOrder attribute to determine order |
| RuleOrder | Rules are evaluated in definition order |
| Sum | Collect and sum numeric outputs |
| Min | Collect and return minimum output |
| Max | Collect and return maximum output |
| Count | Collect and count matching rules |

    pub id: String,

   - `Priority`: Sort by ruleOrder, then apply First behavior
   - `RuleOrder`: Maintain definition order, apply First behavior

3. **Input Entry Evaluation**:
   - Parse and evaluate FEEL expression in inputEntry.text
   - Return true/false for match
   - Handle special values like "A" (any), "-" (skip)

4. **Output Generation**:
   - Convert outputEntry.text to correct type based on OutputClause.typeRef
   - Support numeric, string, boolean types
