Implement the three ordering-based hit policies in `engine/src/dmn/decision_table.rs`.

**PRIORITY (DMN Clause 8.2.12):**
- Zero matches: return null per output column with defaults (same as other policies)
- One or more matches: select the match whose output column value appears HIGHEST in the output clause's `allowedValues` enumeration order
  - Parse the allowedValues on the first output clause to get the enumeration list
  - Find each matching rule's output value position in that enumeration
  - Select the rule with the highest position (index 0 = lowest priority, last index = highest)
  - If a rule's output value is NOT in the enumeration: skip it (do not include in candidates) — only rules with valid enumerated values compete for priority selection
- Output shape: single Value (or context for multi-output) from the winning rule

**OUTPUT ORDER (DMN Clause 8.2.12):**
- Zero matches: return null per output column with defaults
- All matching rules' outputs, sorted by the output column's allowedValues enumeration order (ascending by position index)
- Rules whose output value is NOT in the enumeration: still included but placed after enumerated values (or at end of list), depending on spec interpretation — actually per DMN spec, OUTPUT ORDER orders ALL matching rule results by the allowedValues; rules outside the enumeration appear last in document order among themselves
- Output shape: always a list Value (`Value::Array`) regardless of single vs multi-output

**RULE ORDER (DMN Clause 8.2.12):**
- Zero matches: return null per output column with defaults
- All matching rules' outputs, in document order (the order they appear in `table.rules`) — this is the simplest ordering: just collect all matches as-is
- Output shape: always a list Value (`Value::Array`)

**Output shape convention for ordering policies:** PRIORITY returns a single Value (or context). OUTPUT ORDER and RULE ORDER return `Value::Array` containing one element per matching rule. Each array element is either the direct output value (single-output table) or a boxed context (multi-output table).

**Dispatch wiring update in evaluate():**
```rust

    HitPolicy::Unique => handle_unique(matches, table),
    HitPolicy::Any => handle_any(matches, table),

    HitPolicy::OutputOrder => handle_output_order(matches, table),
    HitPolicy::RuleOrder => handle_rule_order(matches, table),

}
```

Implement the COLLECT hit policy with all four built-in aggregators in `engine/src/dmn/decision_table.rs`.

**COLLECT (DMN Clause 8.2.12):**
- Collects ALL matching rules' outputs into a list, then optionally applies an aggregator function
- The aggregation attribute on the decision table (`table.aggregation`) determines which aggregator to apply; if absent, return the raw list

**Aggregator implementations:**

`SUM`: Sum all output values (must be numeric). Empty → null. Non-numeric → `DecisionTableError::AggregatorMismatch`.
```rust
fn aggregate_sum(values: &[Value]) -> Value {
    // Filter to numeric only; if any non-numeric found, return AggregatorMismatch error
    // If empty list, return Value::Null
    // Otherwise sum all Decimal values
}
```

`MIN`: Minimum of all output values. Empty → null. Non-numeric → `DecisionTableError::AggregatorMismatch`.
```rust
fn aggregate_min(values: &[Value]) -> Value {
    // Filter to numeric only; if any non-numeric found, return AggregatorMismatch error
    // If empty list, return Value::Null
    // Otherwise find minimum Decimal value
}
```

`MAX`: Maximum of all output values. Empty → null. Non-numeric → `DecisionTableError::AggregatorMismatch`.
```rust
fn aggregate_max(values: &[Value]) -> Value {
    // Filter to numeric only; if any non-numeric found, return AggregatorMismatch error
    // If empty list, return Value::Null
    // Otherwise find maximum Decimal value
}
```

`COUNT`: Count of all matching rules (regardless of output type). Empty → `Value::Number(Decimal::ZERO)`.
```rust
fn aggregate_count(values: &[Value]) -> Value {
    // Always returns a Number — count of elements in the list
    // Empty list → Decimal::ZERO, not null
}
```

**COLLECT dispatch:**
```rust

    // 2. If table.aggregation is Some(aggregator): apply the aggregator to the collected values
    // 3. If table.aggregation is None: return the raw list as Value::Array
}
```

**Empty-match semantics (DMN-20 requirement):**
- SUM([]) → null (not zero, not error)
- MIN([]) → null
- MAX([]) → null  
- COUNT([]) → 0 (Decimal::ZERO, NOT null — this is the spec exception for COUNT)

**Output shape:** With aggregation: return the aggregated scalar Value directly. Without aggregation: return `Value::Array` of all matching rules' outputs.
