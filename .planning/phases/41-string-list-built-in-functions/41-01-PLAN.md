    Add a `built_in_filter` function in `engine/src/dmn/feel/builtins.rs` that implements the DMN `filter(list, function)` built-in:

    1. Validate args: `args.len() >= 2`, args[0] is `Value::Array`, args[1] is `Value::Function`.
    2. For each element in the list, apply the function via `lambda_apply` from `eval.rs`.
    3. Collect elements where the function returns a truthy value.
    4. Return the filtered list as `Value::Array`.

    The function signature: `fn built_in_filter(args: &[Value]) -> Value`

    Implementation:
    ```rust
    fn built_in_filter(args: &[Value]) -> Value {
        if args.len() < 2 {
            return Value::Null;
        }
        let list = match &args[0] {
            Value::Array(elems) => elems.clone(),
            Value::Null => return Value::Null,
            _ => return Value::Null,
        };
        let func = match &args[1] {
            Value::Function(f) => f.clone(),
            Value::Null => return Value::Null,
            _ => return Value::Null,
        };
        if func.body.is_none() {
            return Value::Null;
        }
        // For each element, apply the function and collect truthy results.
        let mut result = Vec::new();
        for elem in &list {
            // Create a single-element args array for the function.
            let elem_args = vec![elem.clone()];
            // Use the evaluator's lambda_apply to invoke the function.
            let scope = func.captured.clone().unwrap_or_default();
            let result_val = crate::dmn::feel::eval::lambda_apply_simple(&func, &elem_args);
            match crate::dmn::feel::coercion::coerce_to_bool(&result_val) {
                Some(true) => result.push(elem.clone()),
                Some(false) => {} // skip
                None => return Value::Null, // null propagation
            }
        }
        Value::Array(result)
    }
    ```

    Note: `lambda_apply_simple` doesn't exist yet. Instead, I need to use the existing `lambda_apply` function from eval.rs. But `lambda_apply` takes AST expressions, not evaluated values. So I need a different approach.

    Alternative approach: Since the filter function receives already-evaluated values (the list elements), I need to create a simple wrapper that invokes the function with evaluated args. The best approach is to:

    1. Create a helper function `apply_function(func: &FeelFunction, args: &[Value]) -> Value` in eval.rs that:
       - Creates a Scope from `func.captured` (or empty scope)
       - Binds param names to the provided values
       - Evaluates `func.body` against that scope
    2. Export this helper as `pub(crate)` so builtins.rs can use it.

    Add the registry entry: `reg!("filter", built_in_filter);` in the list family section of `builtin_registry()`.

    Add unit tests in the `mod list` test block:
    - `filter_basic`: filter([1, 2, 3, 4], function(x) x > 2) → [3, 4]
    - `filter_empty`: filter([], function(x) x > 2) → []
    - `filter_null_list`: filter(null, function(x) x > 2) → null
    - `filter_no_function`: filter([1, 2], null) → null
    - `filter_all_match`: filter([1, 2, 3], function(x) true) → [1, 2, 3]
    - `filter_none_match`: filter([1, 2, 3], function(x) false) → []

    Do NOT modify the existing `filter` expression evaluator (target[predicate] in eval.rs). Do NOT add f64 anywhere.
