# Rule Ownership Decisions (AUTH-03 from ROADMAP)

## Ownership Model:
- Each rule has an owner (user_id reference)
- Owner has stewardship responsibilities for their rules
- Owners can be reviewers on approval workflows for their own rules
- Admins can reassign ownership

## Stewardship Features:
1. Rule notifications: Owners get alerts for approvals on their rules
2. Ownership transfer: Admin or current owner can assign new owner
3. Delegation: Owner can delegate review authority to other reviewers

# PostgreSQL Schema Updates
```sql
-- Add owner column to rules table
ALTER TABLE rules ADD COLUMN owner_id TEXT REFERENCES users(username);

-- Index for owner queries
CREATE INDEX idx_rules_owner ON rules(owner_id);

-- Table for role assignments
CREATE TABLE user_roles (
    id UUID PRIMARY KEY,
    user_id TEXT NOT NULL REFERENCES users(username),
    role_name VARCHAR(50) NOT NULL DEFAULT 'author',
    granted_by TEXT REFERENCES users(username),
    created_at TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(user_id, role_name)
);

-- Table for rule ownership assignments
CREATE TABLE rule_ownership (
    id UUID PRIMARY KEY,
    rule_id TEXT NOT NULL REFERENCES rules(id),
    owner_id TEXT NOT NULL REFERENCES users(username),
    assigned_by TEXT REFERENCES users(username),
    reason TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);
```
