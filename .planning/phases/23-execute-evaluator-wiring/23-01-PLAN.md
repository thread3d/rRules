<objective>
Unblock compilation of the pluggable-engine surface and lay the trait/registry foundation that every later Phase 23 plan depends on.

Purpose: The v3.0 engine modules have never compiled — an absolute `engine::` import path (L-01) fails E0433 inside the `engine` crate. Until this is fixed, no engine feature can be enabled on the api crate and the ExecutionEngine trait cannot carry the new `load_ruleset`/`get_facts` bridge (L-02). This plan fixes the import in all four modules, extends the trait and EngineResult, registers all four factories (D-01 foundation), and enables all four features on the api crate.

Output: A compiling engine surface with a trait that can accept a RuleSet and expose post-execution facts, a registry that truthfully advertises all four engines, and an api crate that links all four engine factories.
</objective>
