<objective>
Roll the direct evaluator out to the remaining three engines (Treat, Leaps, Phreak) so `engine: "treat"|"leaps"|"phreak"` actually fires rules — not just Rete.

Purpose: D-01 locks the decision to implement the direct interpreter on ALL FOUR engines, and D-02 requires a per-engine score+10 test proving each fires honestly. Registering all four factories (Plan 01) without working evaluators would make `available_engines()` a lie — selecting "treat" would hit the trait default `Err` and the API would 500. This plan mirrors the Rete evaluator (Plan 03) onto the other three engines and pins each with its own keystone test.

Output: Four engines that all honestly evaluate rules through the same direct-interpreter contract, each proven by a score+10 integration test. The `engine` param is truthful for every advertised name.
</objective>
