  <action>Expand the Wave 1 tck_sweep.rs to execute vectors through ALL three layers (parser, evaluator, exporter) and produce a comprehensive results report.

**Layer dispatch logic per vector category:**

1. **Parser-only vectors** (import validation): All directories with .dmn files that test import correctness — parse the DMN, verify it round-trips through export and re-parse using `structurally_equal()`. This covers: 0002-input-data-number, all simpletable-*, all hit-policy tests.

2. **Parser + Evaluator vectors** (FEEL expression evaluation): Directories with -test-*.xml files that contain expected FEEL expression results. Parse the test XML to extract input scope and expected output value, then:
   - For unary test vectors: parse .dmn, evaluate the decision table with provided inputs using `DecisionEvaluator::evaluate()`, compare outputs against expected values
   - For FEEL expression vectors (0050-0103): extract the expression text from the .dmn `<literalExpression><text>...</text></literalExpression>`, parse it via `feel_parser::parse_expression()`, evaluate with provided scope, compare Value result

3. **Parser + Exporter round-trip** (structural fidelity): For each .dmn file:
   - Parse to IR: `ir1 = parse_dmn(dmn_content)`
   - Export to XML: `xml = export_dmn(&ir1)`
   - Re-parse exported: `ir2 = parse_dmn(xml)`
   - Structural compare: `structurally_equal(original_xml, exported_xml)` — this is the DMN-06 + DMN-07 gate

4. **DMNDI round-trip vectors** (DMN-07 specific): For directories that contain DMNDI layout data (`dmndi:DMNDI` elements in the .dmn):
   - Parse → Export → Re-parse cycle
   - Verify `ir1.diagrams == ir2.diagrams` (structural IR equality for diagrams field)
   - Verify exported XML contains `<dmndi:DMNDI>` block with shapes, edges, and labels preserved

**For each failing vector:**
- Record the failure mode: parse_error, export_mismatch, evaluation_mismatch, dmdi_loss
- Attempt root cause analysis based on error message:
  - Parse error → likely XXE rejection (expected), namespace issue, or missing feature
  - Export mismatch → attribute order difference (structural compare should pass?), CDATA handling, DMNDI omission
  - Evaluation mismatch → FEEL semantics bug, type coercion issue, built-in function gap
  - DMNDI loss → diagrams not populated during parse, or not emitted during export
