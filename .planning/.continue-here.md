## The gaps to close (from the audit + integration checker)

Root cause cluster — all frontend↔backend wiring:
1. **BaseURL mismatch** — frontend `baseURL: /api/v1` (`frontend/src/api/client.ts:6`, `.env.development`, `.env.production`) vs backend `/v1` scope (`api/src/main.rs:96`, no `/api`). Every axios request → 404. Fix: align to `/v1` OR add backend `/api` scope + vite rewrite.
2. **AuthProvider never mounted** — `frontend/src/main.tsx:19-26` renders `RouterProvider` with no `AuthProvider`; `useAuth()` throws (`auth-context.tsx:152-154`); `usePermission` (List.tsx:22, governance hooks) crashes on render.
3. **Incomplete router** — `frontend/src/routes/_layout.gen.ts:6-20` routeTree only registers `/` and `/rules`. ~10 components orphaned: monitoring Dashboard, ApprovalQueue, AuditLogViewer, BranchManager, RuleEditor, DecisionTable, HitPolicySelector, DeadRuleReport/RuleCoverage dashboards.
4. **Stub/mock governance UIs** — `AuditLogViewer.tsx:27-38` hardcoded mock events (never calls `/v1/audit`); `BranchManager.tsx:8-10,70-83,113-116` fetch/merge/create commented-out stubs.
5. **Metrics frontend path** — `useEngineMetrics.ts:111,142` fetches `/api/v1/metrics` (nonexistent); backend serves root `/metrics` + `/v1/monitoring/engine-state`. Stale issue #3 still present.
6. **WebSocket not registered** — `configure_metrics_ws` (`api/src/websocket.rs:30-33`) defined but never called in `main.rs`; handler is a stub.
7. **Auth middleware never wrapped** — `requires_auth` (`api/src/middleware/auth.rs:6`) never `wrap()`ed in `main.rs`. No `/v1/*` route protected (GOV-01 not enforced).
8. **Latent** — `frontend/src/api/rules.ts:48,60` call unregistered backend routes (`PATCH /rules/{id}/status`, `GET /rules/search`).
